Project Timeline · Gantt Chart

Jadwal proyek, task, dan sub-task dalam satu timeline 10 minggu.
Bar biru = terjadwal/berjalan, hijau = selesai, merah = terlambat. Jika jadwal sub-task belum diisi, timeline menggunakan jadwal task induk. Garis waktu menampilkan 70 hari dari tanggal awal yang dipilih.

Ringkasan periode

Catatan pelaporan

Laporan harian menampilkan aktivitas sesuai tanggal mulai/selesai atau tanggal update. Laporan mingguan memakai rentang Senin–Minggu. Laporan bulanan mengikuti bulan yang dipilih. Progress adalah posisi terakhir saat laporan dibuat.

Untuk laporan historis yang akurat, lakukan update sub-task setiap hari. Aplikasi menyimpan tanggal mulai, tanggal selesai, dan riwayat perubahan status.

Sinkronisasi Cloud

Login admin untuk menyinkronkan ProjectPulse antar komputer. Pada koneksi pertama, Anda memilih apakah data lokal dikirim ke cloud atau data cloud dimuat ke browser ini.

Belum terhubung. Akun perlu diberi peran admin ProjectPulse.

Backup & Restore

Simpan data proyek sebagai file JSON agar bisa dipindahkan atau dipulihkan di perangkat lain.

Bagikan link update PIC

Buat link setelah login cloud. PIC dapat membuka melalui HP atau komputer dan mengirim update langsung ke data cloud.

Link khusus untuk daftar sub-task PIC tersebut dan kedaluwarsa setelah 14 hari.

Petunjuk penggunaan

  1. Buat proyek dan tentukan PIC, tanggal mulai, serta target selesai.
  2. Buat task utama, lalu tambahkan sub-task beserta PIC dan jadwalnya.
  3. Update status sub-task setiap hari. Tanggal mulai dan selesai dapat diisi otomatis.
  4. Gunakan Report Center untuk membuat laporan harian, mingguan, bulanan, atau follow-up PIC.
  5. Backup JSON sebagai salinan pemulihan. Sinkronisasi perangkat dilakukan melalui cloud.

Pengaturan data

Hapus seluruh data dari browser ini. Tindakan ini tidak dapat dibatalkan kecuali Anda memiliki backup.
